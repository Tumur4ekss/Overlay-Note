# Overlay Note

**Overlay Note** — это компактная и удобная утилита для Windows, написанная на Python (Tkinter) и сворачивающаяся в системный трей, предназначенная для быстрого просмотра содержимого буфера обмена поверх всех окон.  
Приложение автоматически определяет, что находится в буфере обмена — текст или изображение, — и выводит его в плавающем окне, а также предоставляет режим быстрого копирования для заметок.

## Основные возможности

* **Универсальный оверлей (`ALT+V`):**
  * Если в буфере обмена **изображение** (скриншот) — открывает компактное плавающее окно с картинкой поверх всех окон.
  * Если в буфере обмена **текст** — открывает плавающий блокнот с поддержкой редактирования и форматирования текста.
* **Режим быстрого копирования (`ALT+B`):**
  * Открывает карточку с текстом из буфера обмена. Клик по тексту мгновенно копирует его обратно в буфер.
* **Перетаскивание текста (Drag-and-Drop):**
  * Возможность выделять и перемещать фрагменты текста с помощью мыши (удерживая ЛКМ) внутри встроенного блокнота.
* **Работа в системном трее:**
  * Работает в фоновом режиме и сворачивается в системный трей.
* **Автосохранение и локализация:**
  * Поддержка **русского** и **английского** языков.
  * Все настройки (тема, язык, горячие клавиши) сохраняются в `%APPDATA%\OverlayNote\config.json` и сохраняются между запусками.

## Установка и использование

### Готовый файл (.exe)
1. Скачайте последнюю версию `overlay_app.exe` из раздела [Releases](https://github.com/Tumur4ekss/Overlay-Note/releases).
2. Запустите `overlay_app.exe` (установка не требуется).
3. Приложение запустится и свернётся в системный трей.
